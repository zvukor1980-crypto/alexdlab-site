Чтение XLSX, XLS, XLSB, ODS и CSV. Экспорт в XLSX, CSV или ODS через SheetJS.

TEXT

Текстовые файлы

TXT, MD, CSV, JSON, XML, HTML, LOG и другие текстовые форматы. Можно открыть, нормализовать UTF‑8 и сохранить в другом текстовом формате.

Для JSON выполняется проверка и красивое форматирование.

FFmpeg загружается только при первом запуске аудио/видео-конвертера. Ядро довольно большое, поэтому первый запуск может быть заметно медленнее. Файл остаётся на устройстве пользователя.
