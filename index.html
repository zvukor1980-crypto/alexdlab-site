Рабочие инструменты

Ниже — реальные модули, которые можно запускать на GitHub Pages. Для тяжёлых форматов есть отдельный блок заказа.

AUDIO / VIDEO

Аудио и видео

MP3, WAV, OGG, FLAC, AAC, M4A, MP4, WebM, MOV, MKV. Видео можно конвертировать или извлечь звук.

FFmpeg загрузится при первом запуске.
IMAGES

Изображения

JPG, PNG, WebP. Можно менять формат, качество и размер.

Если ширина/высота пустые — сохраняется исходный размер.
EXCEL / CSV

Таблицы

XLSX, XLS, XLSB, ODS, CSV, TSV. Экспорт в XLSX, CSV, ODS, JSON.

Сложные формулы и оформление могут отличаться после смены формата.
PDF

PDF: объединить / разделить

Объединение нескольких PDF в один и разделение PDF на отдельные страницы.

Файлы обрабатываются локально через pdf-lib.
ZIP

ZIP архивы

Создать ZIP из нескольких файлов или распаковать ZIP прямо в браузере.

RAR/7Z требуют серверной обработки.
TEXT

Текст и JSON

TXT, MD, JSON, CSV, XML, HTML. Предпросмотр, форматирование JSON и сохранение.

JSON будет проверен и красиво отформатирован.
DATA

Base64 и хеши

Файл в Base64, Base64 в файл, SHA‑1, SHA‑256, SHA‑512.

Для Base64 → файл вставьте строку в поле результата.
PRO FORMATS

DJVU, CAD, схемы

DJVU→PDF, DWG/DXF, KiCad, Gerber, Eagle, EPUB/FB2/MOBI, RAR/7Z. Для них нужен сервер или ручная обработка.

Отправить задачуЗапросить backend
На GitHub Pages эти форматы нельзя честно сделать полностью надёжными без сервера.
