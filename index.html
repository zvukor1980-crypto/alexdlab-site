Рабочие инструменты

Это реальные модули, которые работают на статическом GitHub Pages без собственного backend.

AUDIO / VIDEO

Аудио и видео

Конвертация MP3/WAV/OGG/FLAC и MP4/WebM. Для больших видео браузеру может не хватить памяти.

FFmpeg загрузится при первом запуске.
IMAGES

Изображения

JPG, PNG, WebP. Формат, качество, ширина и высота.

Пустые размеры = исходный размер.
EXCEL / CSV

Таблицы

XLSX, XLS, XLSB, ODS, CSV, TSV → XLSX, CSV, ODS или JSON.

Сложное форматирование может измениться.
PDF

Объединить / разделить PDF

Несколько PDF → один файл или один PDF → отдельные страницы.

Обработка локальная.
ZIP

ZIP архивы

Создать ZIP из нескольких файлов или распаковать обычный ZIP.

RAR и 7Z требуют backend.
TEXT / JSON

Текстовые файлы

Открыть TXT/MD/JSON/XML/CSV/HTML, отредактировать и сохранить.

JSON проверяется перед сохранением.
DATA

Base64 и SHA

Файл → Base64 и SHA-1 / SHA-256 / SHA-512.

PRO

DJVU, CAD, схемы и eBooks

DJVU→PDF, DWG/DXF, KiCad, Gerber, Eagle, EPUB/FB2/MOBI, RAR/7Z — для них нужен специализированный backend.

Отправить задачу
Не притворяемся, что GitHub Pages умеет то, для чего нужен сервер.
