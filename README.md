# Alex D Lab — Analog & Digital

Алексей · Хайфа, Израиль. Перезапись аудиокассет на компьютер, запись музыки на кассеты и CD.

Статический сайт: index.html, styles.css, app.js. Публикация: GitHub Pages. Форма: FormSubmit → digitalaleksei@gmail.com; при первом использовании получателю может потребоваться активация по письму FormSubmit. Для проверки отправки сервис должен вернуть success=true; это подтверждает приём сервисом, но не доставку письма.

Старое содержимое удалено из текущего дерева; история Git сохранена. Контактные данные посетителей не хранятся в репозитории или localStorage.
