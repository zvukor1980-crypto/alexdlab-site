# RepairLab Bridge для MacBook Air M2

1. Подключите iPhone кабелем к Mac и разблокируйте его.
2. При первом подключении подтвердите «Доверять этому компьютеру».
3. Дважды нажмите `START-REPAIRLAB.command` и не закрывайте окно Terminal.
4. Сайт RepairLab откроется автоматически и покажет состояние подключения.

Bridge работает только на `127.0.0.1`, принимает команды только от официального сайта RepairLab и использует случайный токен текущего запуска. Серийные номера и данные устройства не отправляются в интернет.

`Update` пытается сохранить пользовательские данные. `Restore` полностью стирает iPhone и требует отдельного подтверждения фразой `СТЕРЕТЬ IPHONE`.
