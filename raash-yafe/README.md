# רעש יפה — Ra'ash Yafe

Музыкальное приложение для iPhone, доступное через Safari → «На экран Домой».

## Возможности
- Первый альбом «אני פה!» с восемью композициями
- Два независимых варианта (A и B) для каждого трека
- Локальное сохранение MP3, WAV, M4A и обложек
- Прикрепление ссылок Suno, без хранения логинов и паролей
- Музыкальный плеер, клипы, новые альбомы
- Офлайн-режим через Service Worker

Данные песен и файлов хранятся в IndexedDB браузера на устройстве. Экспорт JSON содержит только список и ссылки, не сами медиафайлы — оригинальные файлы храните также отдельно.

## Установка
Откройте опубликованный HTTPS-адрес приложения в Safari на iPhone, нажмите «Поделиться» → «На экран Домой» → «Добавить».

## Безопасность
Не вводите пароль Suno в приложение. Перейти в свою библиотеку можно через официальную страницу Suno.
